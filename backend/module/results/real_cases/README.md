# 실제 결제 사례 6명 (원카드 혜택 재계산 · ML 학습용)

팀원이 `실제결제_양식`으로 제출한 한 달 결제 내역을 동백전 + BNK 카드 1장(원카드) 규칙으로 다시 계산한 결과입니다.

| 파일 | 내용 |
|---|---|
| `real_cases_transactions.csv` | 거래 279건 · 정규화 컬럼 + 원카드 계산 결과 (ML 입력/정답 후보) |
| `real_cases.json` | 대시보드 P2 "실제 사례" 화면용 요약 |
| `load.py` → `calc.py` | 엑셀 → raw.json → 재계산 (엑셀·규칙표 경로는 파일 안에서 지정) |

## 계산 규칙 (단순화판, 엔진과 같은 규칙표 사용)
- BNK 카드 6종 규칙: 합성데이터 v3.3 `BENEFIT_RULE.csv`·`BENEFIT_CAP_TIER.csv` (건당·월 한도, 월 횟수, 전월 실적 반영). 포인트형 혜택은 0원
- 동백전: 부산 구·군 오프라인 결제 + 가맹 "예"면 10%, 월 캐시백 대상 50만 원 한도. 매출 구간은 10억 이하로 가정
- 원카드는 실물 태그 결제로 가정 → 현장 간편결제·결제방식 미기입도 오프라인으로 봄. 현금·계좌이체는 0원
- 전월 실적: 제출값, 없으면 그 달 카드 결제액으로 대체
- `onecard_*` = 가맹 "예"만, `onecard_wide_*` = 가맹 "모름"까지 가맹으로 본 상한
- 추천 카드 = 6종 중 원카드 합계가 가장 큰 카드
