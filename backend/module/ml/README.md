# 원카드 개인화 추천 ML (v0)

보정 데이터 240명(v3.4 4개 시나리오 결과)으로 학습하고, 실제 사례 T1·T4에 적용합니다.

| 모델 | 무엇을 예측 | 입력 | 교차검증(5겹) |
|---|---|---|---|
| 랜덤포레스트 회귀 | 월 혜택 증가액 (원패스+충전 상한, S11−S00) | 업종별 결제 비중, 결제 경로 비중, 동백전 가맹 오프라인 비중, 결제 건수·금액, 지갑 상태, 카드 수, 연령 | MAE 7,626원 (평균값 예측 14,156원), R² 0.56 |
| 랜덤포레스트 분류 | 동백전과 연결할 BNK 카드 (규칙표로 6종 중 월 혜택이 가장 큰 카드) | 위와 같음 | 정확도 70% (최빈 카드 40%) |
| K-means (5개) | 소비 모습이 비슷한 고객 묶음 | 업종·경로 비중, 건당 금액 | — |

- 실행: `python train.py <결과폴더> <MERCHANT.csv> <프로필.json> <실제사례.json> <출력.json> <BENEFIT_RULE 폴더>`
- 원패스만(S01−S00) 증가액 예측은 R² 0.0으로 설명력이 없어 화면에 쓰지 않음
- 실제 사례는 학습 데이터에 없는 업종(교통·구독·여행)이 많으면 신뢰가 낮음 (T4는 91%)
- 보정 데이터 자체가 규칙 엔진 결과라, 이 모델은 "규칙 엔진을 결제 패턴만으로 근사"하는 단계임
